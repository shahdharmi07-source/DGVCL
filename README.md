# Smart Energy Portal

Smart Energy Portal is a web-based electricity consumer management
system developed for the Digital Gujarat Power System (DGPS).

## Features

- Consumer Registration
- Consumer Login
- OTP Verification
- Consumer Dashboard
- Electricity Bill Management
- Download Electricity Bill
- Online Bill Payment
- Payment History
- Complaint Registration
- Usage Report
- Notifications
- Admin Management

## Technologies

Frontend:
- React.js
- CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB
